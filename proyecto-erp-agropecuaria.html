ERP para tienda de insumos agrícolas

Sistema de gestión empresarial para una agropecuaria: ventas, inventario, compras y un módulo contable integrado.

ERP

Descripción del proyecto

Sistema ERP web pensado para una tienda de insumos agrícolas que necesita centralizar toda su operación diaria: desde el catálogo de productos hasta la contabilidad.

El proyecto se desarrolla con un entorno en contenedores Docker, control de versiones en GitHub y está planificado para desplegarse en un servidor de hosting en producción.

Funcionalidades principales

  • Vademécum de productosCatálogo de insumos agrícolas con su información técnica.
  • Compras y almacénRegistro de compras a proveedores y control de stock por almacén.
  • Ventas y punto de ventaMódulo POS con emisión de boletas.
  • DespachoSeguimiento de la entrega de productos vendidos.
  • Módulo contableContabilidad integrada, diseñada como un módulo independiente.
